# Calc Part 1

## PL

W tej lekcji zaczynamy budowę prostego kalkulatora w C++. Tworzymy pierwszy program konsolowy, wczytujemy dwie liczby od użytkownika i pokazujemy wynik podstawowego działania. To wprowadzenie do pracy z `main`, `std::cout`, `std::cin`, zmiennymi oraz kompilacją programu z terminala.

### Narracja

Zaczynamy budowę kalkulatora w C++ od najprostszego programu konsolowego. Pokażemy, czym jest funkcja `main`, jak wypisać tekst na ekran, jak wczytać dane od użytkownika i jak zapisać je w zmiennych. Na końcu skompilujemy program i uruchomimy go z terminala.

### Co uczeń poznaje

- strukturę prostego programu C++
- `main`
- `std::cout`
- `std::cin`
- zmienne liczbowe
- podstawową kompilację z terminala

## EN

In this lesson we start building a simple calculator in C++. We create the first console program, read two numbers from the user, and display the result of a basic operation. This is an introduction to `main`, `std::cout`, `std::cin`, variables, and compiling a program from the terminal.

### Narration

We start building a calculator in C++ with the simplest console program. We show what the `main` function is, how to print text to the screen, how to read user input, and how to store values in variables. At the end, we compile and run the program from the terminal.

### What the student learns

- the structure of a simple C++ program
- `main`
- `std::cout`
- `std::cin`
- numeric variables
- basic compilation from the terminal
