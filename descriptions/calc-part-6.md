# Calc Part 6

## PL

W tej lekcji zmieniamy kalkulator w program interaktywny, który działa wiele razy bez ponownego uruchamiania. Dodajemy pętlę `while`, opcję `0. Exit` oraz powrót do menu po wykonaniu działania. Użytkownik może wykonać kilka obliczeń po kolei, a program kończy się dopiero po wybraniu opcji wyjścia.

### Narracja

Do tej pory kalkulator wykonywał jedno działanie i kończył pracę. W tej lekcji dodajemy pętlę, dzięki której program będzie wracał do menu po każdym obliczeniu. Dodamy też opcję `0. Exit`, żeby użytkownik mógł świadomie zakończyć program.

### Co uczeń poznaje

- pętlę `while`
- powtarzanie programu bez restartu
- warunek zakończenia
- `break`
- opcję wyjścia z menu
- podstawowy przepływ aplikacji interaktywnej

## EN

In this lesson we turn the calculator into an interactive program that can run multiple times without restarting. We add a `while` loop, a `0. Exit` option, and return to the menu after each operation. The user can perform several calculations in a row, and the program ends only after choosing the exit option.

### Narration

Until now, the calculator performed one operation and then ended. In this lesson, we add a loop so the program returns to the menu after each calculation. We also add a `0. Exit` option so the user can intentionally close the program.

### What the student learns

- the `while` loop
- repeating a program without restarting
- an exit condition
- `break`
- an exit option in a menu
- the basic flow of an interactive application
