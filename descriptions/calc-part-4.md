# Calc Part 4

## PL

W tej lekcji porządkujemy projekt i dzielimy kalkulator na kilka plików. Deklaracje funkcji trafiają do `calc.hpp`, implementacje do `calc.cpp`, a komunikacja z użytkownikiem zostaje w `main.cpp`. To pierwszy krok do bardziej profesjonalnej organizacji kodu C++ oraz pracy z plikami nagłówkowymi.

### Narracja

W tej lekcji rozbijamy kalkulator na kilka plików. Deklaracje funkcji przenosimy do `calc.hpp`, implementacje do `calc.cpp`, a kod odpowiedzialny za rozmowę z użytkownikiem zostawiamy w `main.cpp`. To pokazuje, jak zaczyna wyglądać prawdziwy projekt C++, kiedy kod przestaje mieścić się wygodnie w jednym pliku.

### Co uczeń poznaje

- pliki `.hpp` i `.cpp`
- deklarację funkcji
- implementację funkcji
- `#include`
- podstawową organizację projektu C++
- kompilację programu z kilku plików

## EN

In this lesson we organize the project and split the calculator into multiple files. Function declarations go into `calc.hpp`, implementations go into `calc.cpp`, and user interaction stays in `main.cpp`. This is the first step toward a more professional C++ project structure and working with header files.

### Narration

In this lesson, we split the calculator into multiple files. Function declarations move to `calc.hpp`, implementations move to `calc.cpp`, and the code responsible for user interaction stays in `main.cpp`. This shows how a real C++ project starts to look once the code no longer fits comfortably in one file.

### What the student learns

- `.hpp` and `.cpp` files
- function declarations
- function implementations
- `#include`
- basic C++ project organization
- compiling a program from multiple files
