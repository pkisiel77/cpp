# Calc Part 4

## PL

W tej lekcji porządkujemy projekt i dzielimy kalkulator na kilka plików. Deklaracje funkcji trafiają do `calc.hpp`, implementacje do `calc.cpp`, a komunikacja z użytkownikiem zostaje w `main.cpp`. To pierwszy krok do bardziej profesjonalnej organizacji kodu C++ oraz pracy z plikami nagłówkowymi.

## EN

In this lesson we organize the project and split the calculator into multiple files. Function declarations go into `calc.hpp`, implementations go into `calc.cpp`, and user interaction stays in `main.cpp`. This is the first step toward a more professional C++ project structure and working with header files.
