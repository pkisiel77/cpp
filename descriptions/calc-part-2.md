# Calc Part 2

## PL

W tej lekcji rozwijamy kalkulator o osobne funkcje dla działań matematycznych. Zamiast trzymać całą logikę bezpośrednio w `main`, tworzymy funkcje takie jak `addition`, `subtraction`, `multiplication` i `division`. Dzięki temu kod staje się czytelniejszy, a każde działanie ma swoje własne miejsce.

## EN

In this lesson we extend the calculator with separate functions for mathematical operations. Instead of keeping all logic directly inside `main`, we create functions such as `addition`, `subtraction`, `multiplication`, and `division`. This makes the code easier to read, with each operation having its own place.
