# Calc Part 2

## PL

W tej lekcji rozwijamy kalkulator o osobne funkcje dla działań matematycznych. Zamiast trzymać całą logikę bezpośrednio w `main`, tworzymy funkcje takie jak `addition`, `subtraction`, `multiplication` i `division`. Dzięki temu kod staje się czytelniejszy, a każde działanie ma swoje własne miejsce.

### Narracja

W tej części zaczynamy porządkować kod kalkulatora. Zamiast pisać wszystkie działania w `main`, tworzymy osobne funkcje dla dodawania, odejmowania, mnożenia i dzielenia. Dzięki temu `main` jest krótszy, a każde działanie ma własną nazwę i własne miejsce w kodzie.

### Co uczeń poznaje

- tworzenie własnych funkcji
- parametry funkcji
- zwracanie wartości przez `return`
- dzielenie programu na mniejsze fragmenty
- czytelniejsze nazwy dla operacji

## EN

In this lesson we extend the calculator with separate functions for mathematical operations. Instead of keeping all logic directly inside `main`, we create functions such as `addition`, `subtraction`, `multiplication`, and `division`. This makes the code easier to read, with each operation having its own place.

### Narration

In this part, we start organizing the calculator code. Instead of writing every operation inside `main`, we create separate functions for addition, subtraction, multiplication, and division. This makes `main` shorter, and each operation gets its own name and place in the code.

### What the student learns

- creating custom functions
- function parameters
- returning values with `return`
- splitting a program into smaller parts
- using readable names for operations
